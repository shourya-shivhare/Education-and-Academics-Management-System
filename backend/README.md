# backend/

Spring Boot 3 (Java 17+) backend using Spring JdbcTemplate with hand-written SQL and Flyway for schema migrations. NO JPA/Hibernate; `ddl-auto` is not used. Java only calls stored procedures/queries — business rules live in MySQL.

This folder will be populated in a later step (pom.xml, src/main/java, application.properties, Flyway migrations config).
